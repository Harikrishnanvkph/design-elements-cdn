# Design Elements CDN

A strictly unique library of 125 handcrafted vector design elements for Canva-style graphic editors, posters, and charts.

Served globally via [jsDelivr](https://www.jsdelivr.com/) and Cloudflare Edge CDN with **0% pressure on your server**.

## CDN Endpoint
```
https://cdn.jsdelivr.net/gh/Harikrishnanvkph/design-elements-cdn@main/catalog.json
```

- **Splatters (25)**: Top border gravity drips, single hanging drip, corner ceiling drips, 360 radial bursts, directional flick splatters, airbrush mist clouds, liquid ink puddles, visceral ooze, two-tone layered splashes.

- **Doodles, Stars & Botanical (25)**: Signature 4-point Canva sparkles, 8-point twinkle stars, sparkle trios, botanical laurel branches, olive wreaths, leaf sprigs, king crowns, queen tiaras, comic POW bursts, speech & thought bubbles, sketchy hearts, cupid arrows, lightning bolts, bullseye targets, sunburst rays, Memphis wave dots, lightbulbs, flames, confetti bursts.
